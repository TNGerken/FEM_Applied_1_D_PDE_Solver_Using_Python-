# FEM_Applied_1_D_PDE_Solver_Using_Python-
This project implements the Finite Element Method (FEM) in Python to solve a 1-D PDE with mixed Dirichlet and Neumann boundary conditions.   We derive the weak form of the PDE, define Lagrange basis functions, assemble the global stiffness matrix and force vector, apply boundary conditions, and compare results to the analytical solution.
